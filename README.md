# lab3
# Прерывания на Arduino (ATmega328P)

Четыре примера работы с прерываниями микроконтроллера ATmega328P (Arduino UNO):
внешние (`INT0`/`INT1`) и внутренние (таймерные, Timer0/Timer1).

## Структура репозитория

| Папка | Задание | Описание |
|-------|---------|----------|
| `task1_external_interrupt/` | Задание 1 | Кнопка на D2 (внешнее прерывание INT0) переключает частоту мигания LED: 1 Гц ↔ 5 Гц. Антидребезг 200 мс. |
| `task2_timer1_100hz/` | Задание 2 | Мигание LED на D13 по прерыванию Timer1 с частотой 100 Гц (OCR1A = 2499, N = 64). |
| `task3_timer0_keyboard/` | Задание 3 | Сканирование матричной клавиатуры 4×4 по прерыванию Timer0 каждые 1 мс (OCR0A = 249, N = 64). Вывод символа в Serial. |
| `task4_timer1_int0_lcd/` | Задание 4 | Timer1 (500 мс, OCR1A = 7811, N = 1024) обновляет счётчик на I2C LCD; INT0 на D2 инициирует сканирование клавиатуры в `loop()`. Клавиша `A` сбрасывает счётчик. |

## Ключевые формулы

Расчёт предзагрузки таймера в режиме CTC:

$$\text{OCR} = \frac{F_{CPU}}{N \cdot F_{int}} - 1$$

| Задание | Таймер | N | F_int | OCR |
|---------|--------|---|-------|-----|
| 2 | Timer1 | 64 | 100 Гц | 2499 |
| 3 | Timer0 | 64 | 1000 Гц | 249 |
| 4 | Timer1 | 1024 | 2 Гц | 7811 |

## Оборудование

- Arduino UNO (ATmega328P)
- LCD 16×2 с модулем I2C
- Матричная клавиатура 4×4
- Светодиод, тактовая кнопка, макетная плата, провода

## Сборка и прошивка

1. Открыть нужный `.ino` в Arduino IDE.
2. Установить библиотеки: `LiquidCrystal_I2C` (для задания 4), `Wire` (встроенная).
3. Выбрать плату **Arduino UNO** и соответствующий COM-порт.
4. Загрузить скетч.

## Примечания по безопасности ISR

- Обработчики короткие: только флаги/инкременты, без `delay()` и `lcd.print()`.
- Разделяемые переменные помечены `volatile`.
- Многобайтные переменные (`unsigned long`) читаются под `noInterrupts()`/`interrupts()`.
- Тяжёлые операции (сканирование, вывод на LCD/Serial) — в `loop()`.
